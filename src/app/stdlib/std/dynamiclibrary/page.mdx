# DynamicLibrary

Cross-platform shared library loader

<H2 id="It">It</H2>

Platform-specific dynamic library handle

<CodeTabs
  uhc={`#if defined(_WIN32) || defined(_WIN64)
  self {
    HINSTANCE handle
    String name
    U8 isValid
  }
#else
  self {
    U0* handle
    String name
    U8 isValid
  }
#endif
  `}
  cpp={`#if defined(_WIN32) || defined(_WIN64)
  struct It {
    HINSTANCE handle;
    String name;
    unsigned char isValid;
  }
#else
  struct It {
    void* handle;
    String name;
    unsigned char isValid;
  }
#endif
  `}
/>

---

<H2 id="load">load</H2>

Load a shared library by name or path

<CodeTabs
  uhc={`DynamicLibrary load(String name)`}
  cpp={`DynamicLibrary::It load(String name);`}
/>

**Parameters**
- `name` — Library name or path

**Returns** — Library object — check isValid before use

---

<H2 id="get">get</H2>

Retrieve a function pointer from a loaded library

<CodeTabs
  uhc={`U0* get(DynamicLibrary dll, String functionName)`}
  cpp={`void* get(DynamicLibrary::It& dll, String functionName);`}
/>

**Parameters**
- `dll` — The dynamic library
- `functionName` — The exported symbol name

**Returns** — Raw function pointer — cast before calling
